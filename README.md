# Hangman Game in Python 🕹️

A beginner-friendly terminal-based Hangman game written in Python.

## Features

- Random word selection from a word list (words.txt)
- ASCII art hangman visuals
- Input validation
- Game replay option

## How to Run

1. Make sure you have Python 3 installed.
2. Clone or download the repo.
3. Open a terminal and run:

```bash
python hangman.py
